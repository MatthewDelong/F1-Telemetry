========================================================
             API MIGRATION & DECOUPLING NOTICE
========================================================

Please Note: 
As of this version, this project has officially removed itself from the original f1nsight fork's external data ecosystem (f1nsight-api-2, f1aapi, f2api). 

We no longer rely on those third-party GitHub Pages repositories for our telemetry, standings, or race results. 

Instead, F1-Telemetry has established its own self-hosted caching architecture and PHP gateway, drawing its Formula 1 data natively from the official Jolpica API to guarantee long-term stability and absolute control over our race updates.

- Matthew Delong & the F1-Telemetry Development Team
